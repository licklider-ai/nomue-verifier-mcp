# Contributing

Bug reports, documentation problems, questions, and other feedback are welcome through
GitHub Issues. Do not include private Records, unpublished data, credentials, or
security-sensitive details in a public issue.

Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

External code and Protocol-semantics contributions are not currently accepted. The MCP
package must remain a thin adapter around the exact published verifier dependency;
statistical, verification, schema, check, and decision-vocabulary changes belong to
their controlling nomue repositories and release processes.
